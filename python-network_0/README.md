# Python - Network #0

Introduction to Python Programming and Databases — ALU.

Bash scripts that use cURL to explore HTTP: request methods, headers,
status codes, response bodies and POST parameters.



Each script takes a URL as its first argument.

    $ ./0-body_size.sh 0.0.0.0:5000
    $ ./4-header.sh 0.0.0.0:5000/route_5

 Files

| File | Description |
| --- | --- |
| 0-body size.sh | Displays the size of the response body in bytes |
| 1-body.sh | Displays the body of a 200 response only |
| 2-delete.sh | Sends a DELETE request and displays the body |
| 3-methods.sh | Lists the HTTP methods the server accepts |
| 4-header.sh | Sends a GET request with a custom header |
| 5-post params.sh | Sends a POST request with two parameters |
