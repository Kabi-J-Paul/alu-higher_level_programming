# Python - Test-driven development

Introduction to Python Programming and Databases — ALU.

Functions written test-first, with interactive doctests in `tests/` and
unittests for `max_integer`. Each function validates its arguments and
raises the appropriate exception on bad input.



## Running the tests

    $ python3 -m doctest ./tests/*
    $ python3 -m unittest tests.6-max_integer_test



| File | Description |
| --- | --- |
| 0-add integer.py | Adds two numbers, casting floats to integers |
| 2-matrix divided.py | Divides every element of a matrix by a number |
| 3-say my name.py | Prints a full name in a fixed format |
| 4-print square.py | Prints a square made of the # character |
| 5-text indentation.py | Prints text with two new lines after . ? and : |
| 6-max integer.py | Returns the largest element of a list |
