# Python - Network #1

Introduction to Python Programming and Databases — ALU.

Python scripts that fetch and manipulate internet resources, first with
the standard library urllib package and then with the requests package.
Covers GET and POST requests, response headers, error handling and JSON.

| File | Description |
| --- | --- |
| 0-hbtn status.py | Fetches the intranet status page with urllib |
| 1-hbtn header.py | Displays the X-Request-Id header with urllib |
| 2-post email.py | Sends a POST request with an email with urllib |
| 3-erro _code.py | Handles HTTPError and prints the status code |
| 4-hbtn status.py | Fetches the intranet status page with requests |
| 5-hbtn header.py | Displays the X-Request-Id header with requests |
| 6-post email.py | Sends a POST request with an email with requests |
| 7-error code.py | Prints the status code when it is 400 or more |
| 8-json api.py | Queries a search API and parses the JSON result |
| 10-my github.py | Displays a GitHub user id via Basic Auth |
