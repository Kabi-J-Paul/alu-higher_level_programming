Python - Inheritance

Project for the Introduction to Python Programming and Databases course at African Leadership University. It covers superclasses and subclasses, method overriding, the built-in functions isinstance, issubclass, type and super, and how to inspect the attributes and methods of any object.
Files

0-lookup.py	lookup(obj) returns the list of attributes and methods of an object
1-my list.py	MyList inherits from list and adds print sorted()

3-is kin _of class.py	is_kind of class(obj, a class) also accepts subclasses
