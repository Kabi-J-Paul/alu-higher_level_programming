Introduction to object-oriented programming in Python. Each file builds a
`Square` class, adding one concept at a time.



| File | Description |
|------|-------------|
| `0-square.py` | Empty `Square` class |
| `1-square.py` | `Square` with a private instance attribute `size` |
| `2-square.py` | Size validation (`TypeError`, ValueError) |
| `3-square.py` | Public instance method `area()` |
| `4-square.py` | `size` property getter and setter |
| `5-square.py` | `my_print()` — draws the square with # |
| `6-square.py` | `position` attribute and offset printing |
